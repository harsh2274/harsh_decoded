PROJECT / 01 FALL 2026

NYC FloodNet & Drainage Infrastructure Mapping

An interactive GIS project exploring urban flood vulnerability across Brooklyn Community District 6 (CD6), New York City, using FloodNet sensor data and drainage infrastructure datasets.

  • Spatial data integration: Combined FloodNet sensor events and NYC catch-basin locations using NYC Open Data, ArcGIS Pro, and ArcGIS Online.
  • Infrastructure analysis: Mapped 1,800+ catch basins and calculated density per square mile to examine drainage distribution.
  • Event visualization: Mapped FloodNet event counts by sensor to identify locations with recurring recorded street-flooding events.
  • Interactive StoryMap: Built a web map with thematic layers, density-based symbology, and a legend.
  • Urban resilience: Compared event patterns with drainage distribution to identify areas for further investigation; this analysis does not establish that low catch-basin density causes flooding.
